# Changelog

## 1.1.0

- Added Python 3 compatibility for OPDS and Calibre REST requests.
- Added Qt 6 scoped-enum compatibility.
- Switched GUI imports to Calibre's `qt.core` compatibility layer.
- Raised the minimum supported Calibre version to 6.0.
- Verified OPDS browsing and acquisition-feed parsing with Project Gutenberg on Calibre 6.3 for Apple Silicon macOS.

## 1.0.0

- Original Calibre OPDS Client release.
